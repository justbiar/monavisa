Mona Visa satıcı paneli

Mona Visa'da abonelik satan satıcıların paneli. Cüzdanla (Sign-In with Ethereum) giriş yapılır. Panelden plan oluşturulur, aboneler, ödemeler ve gelir izlenir, ödeme linkleri, API anahtarları, özellik eşlemeleri ve webhook'lar yönetilir.

Merchant dashboard for Mona Visa, non-custodial subscriptions and agent payments on Monad. Merchants sign in with their wallet to create plans, track subscribers and revenue, and manage payment links, API keys and webhooks.
